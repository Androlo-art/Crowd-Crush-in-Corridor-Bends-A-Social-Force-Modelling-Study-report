# results / 02_open_and_restricted_bend

Final data for the open-bend capacity and the restricted-exit crush (Ch4 + App). Each
folder has `aggregated.csv`, `run_info.txt` and `grids/` (per-cell density / contact /
pressure fields, needed for the heatmap figures).

| Folder | Used for |
|---|---|
| `open_bend_capacity/` | open-bend capacity, crowd-pressure, capacity `--open` reference |
| `restricted_bend_bottleneck/` | bottleneck crush, restricted-exit density |

Figures: `report_figures/plot_bend_report_figures.py` and `plot_bottleneck.py`. No rerun needed.
